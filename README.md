# Archived Mini Projects

A collection of older side projects and programming experiments by SoftDevAndy.

## Projects

- [iss](iss/) - A web app that tracks the International Space Station on Google Maps using Open Notify coordinates.
- [mapeditor](mapeditor/) - A Java tile map editor with PNG and text export, map import, and a grid overlay.
- [pathfinding](pathfinding/) - A Unity A* pathfinding experiment on randomly generated grids. Requires a commercial Vectrosity license.
- [pong](pong/) - A two-player Java Pong game with shared keyboard controls and sound effects.
- [adventure](adventure/) - A Java text adventure about exploring a locked room and finding the combination to escape.
- [bealecipher](bealecipher/) - A Java tool for parsing Beale cipher data and analysing number frequencies.
- [ciphertools](ciphertools/) - Java command-line tools for classical ciphers, Base64 conversion, and frequency analysis.
- [conwaysgameoflife](conwaysgameoflife/) - An interactive Java Game of Life simulation with editable cells and step-by-step playback.
- [enigmamachine](enigmamachine/) - A Java Enigma-style encryption demo with configurable rotor, plugboard, and reflector wiring.
- [wordchart](wordchart/) - A Python script that charts the most frequent words on a webpage after filtering common words.
- [rustoxidechatmoderator](rustoxidechatmoderator/) - DoomChat, an Oxide/uMod Rust server plugin for moderation, private messages, trade chat, and clan chat.
